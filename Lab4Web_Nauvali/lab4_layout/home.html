Memahami CSS Layout

CSS layout mengatur posisi dan ukuran elemen pada halaman web. Pada latihan ini digunakan float untuk menyusun kolom, clear untuk menghentikan efek float, serta box model untuk mengatur margin, border, padding, dan content.

HTML Semantik

Elemen seperti header, nav, main, section, article, aside, dan footer membantu memberi makna pada bagian halaman. Struktur semantik membuat dokumen lebih terorganisasi dan mudah dipahami.
