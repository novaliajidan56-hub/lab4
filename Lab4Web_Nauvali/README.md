## Isi folder
- `lab4_box.html`: latihan Box Element, float, dan clear.
- `lab4_layout/home.html`: halaman utama dengan navigasi, hero panel, konten, sidebar, dan footer.
- `lab4_layout/about.html`: halaman About berisi deskripsi dan portofolio.
- `lab4_layout/contact.html`: halaman Contact berisi form nama, email, dan pesan.
- `lab4_layout/style.css`: aturan tampilan untuk halaman layout.

## Cara menjalankan
1. Ekstrak folder `Lab4Web_Nauvali`.
2. Buka folder menggunakan Visual Studio Code.
3. Buka `lab4_box.html` atau `lab4_layout/home.html` melalui browser.
4. Untuk menjalankan form kontak secara lokal, buka `lab4_layout/contact.html`. Form ini hanya contoh tampilan dan belum mengirim data ke server.

## Ringkasan tahapan praktikum
1. Membuat Box Element dengan `div`.
2. Menambahkan `float: left` untuk menyusun elemen sejajar.
3. Menambahkan `clear: left` pada Div 4 agar berada di bawah baris float.
4. Membuat struktur layout semantik: header, nav, main, aside, article, dan footer.
5. Menambahkan CSS untuk header dan navigasi.
6. Membuat hero panel.
7. Membuat kolom main dan sidebar.
8. Menambahkan widget sidebar dan footer.
9. Menambahkan tiga kartu konten dan artikel.
10. Membuat halaman About dan Contact sebagai tugas lanjutan.
